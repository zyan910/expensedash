# 💳 Expense Dashboard

Personal offline dashboard that parses credit card PDF statements into an interactive expense view. Runs 100% locally in the browser via `PDF.js` with zero backend.

## Quick Reference
* **Multi-PDF / MoM:** Select multiple statements at once to consolidate totals and see Month-over-Month (`▲`/`▼`) spend deltas.
* **Rename Merchants:** Tap any merchant name to save a permanent alias in `localStorage`.
* **Reimbursable Flag (`💼`):** Tap the briefcase icon on any row to deduct it from net personal spend and group it at the bottom.
* **Exports:** Download a standalone `.html` snapshot or a `.csv` file (with reimbursable tags) for spreadsheet/database imports.
